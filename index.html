Por que o DocX

Arquivos que são seus

Cada nota é um arquivo .md numa pasta do seu computador. Abre em qualquer editor, funciona offline e não fica preso a nenhum app.

Sincroniza pelo seu Git

A cópia online fica num repositório seu (GitHub, GitLab…), com histórico de versões de cada nota. Nenhum servidor nosso guarda nada.

Privado por padrão

Sem cadastro, sem telemetria e sem anúncios dentro do app. A interface não faz chamadas de rede: só o Git, quando você sincroniza.

Tudo o que você precisa para pensar por escrito

Veja o DocX funcionando de verdade: os vídeos abaixo foram gravados no próprio app.

Escreva em Markdown e veja a formatação na hora

O Live Preview transforma o Markdown enquanto você digita. Ctrl+E alterna entre edição e leitura.

  • Tabelas, checklists, notas de rodapé e realce de código
  • Fórmulas (KaTeX), diagramas Mermaid e callouts
  • Propriedades em YAML, tags e modo Vim opcional

Ligue ideias com [[links]]

Digite [[ e escolha a nota. Passe o mouse para ver a prévia, e veja no painel lateral tudo o que aponta para a nota atual.

  • Backlinks, menções não ligadas e links de saída
  • Renomear uma nota atualiza todos os links para ela
  • Transclusão: mostre uma nota (ou um trecho) dentro de outra

Pense no quadro branco

Monte mapas com cartões e notas no canvas, ligados por setas, ou desenhe à mão livre. Diagramas também ficam no vault, ao lado das notas.

  • Canvas com cartões de texto, notas e grupos
  • Desenhos à mão livre e diagramas
  • Imagens, PDFs, áudio e vídeo: cole ou arraste para a nota

Tudo a um atalho de distância

Busca instantânea em todas as notas, troca rápida com Ctrl+O e paleta de comandos com Ctrl+P.

  • Busca por texto, tags e caminhos
  • Tela dividida, abas e temas claro e escuro
  • Nota diária e modelos com um atalho

Assistente Claude

Converse com as suas notas usando o Claude

O DocX se conecta ao Claude Code instalado no seu computador, com o login e a assinatura da sua conta do Claude. Não há chave de API para configurar.

  • Só lê: o Claude procura e lê arquivos dentro do vault, e nada fora dele. Não roda comandos nem acessa a internet.
  • Você decide: para criar ou mudar algo, ele propõe, e cada proposta tem Aplicar e Descartar. Alterações aparecem como diferença.
  • Cria de tudo: notas, pastas, canvas, desenhos e diagramas.
  • Conversas por vault: retome de onde parou; escolha Opus, Sonnet ou Haiku.
  • Funciona no Windows (inclusive com o Claude Code no WSL) e no Linux. Abra com Ctrl+Shift+L.

Sincronização

Backup e histórico no seu repositório

Use um repositório privado no GitHub, no GitLab ou onde preferir. O login é feito pelo próprio Git do seu computador: o DocX nunca vê a sua senha.

Crie um repositório

Um repositório privado e vazio, por exemplo notas, na sua conta.

Cole a URL no DocX

Em Configurações › Vault e sincronização, escolha Git e cole a URL do repositório.

Pronto

O DocX envia e busca as mudanças sozinho. Cada nota ganha histórico de versões.

Download

Baixe grátis

Última versão. Sem cadastro.

Windows

Windows 10 e 11, 64 bits. Instalador com atalhos na Área de Trabalho e no Menu Iniciar.

Baixar .exe

Ubuntu / Debian

Pacote .deb, 64 bits. Instala pelo apt ou pela Central de Aplicativos.

sudo apt install ./DocX-linux-amd64.deb Baixar .deb

Qualquer Linux

AppImage portátil, 64 bits. Não precisa instalar: dê permissão e execute.

chmod +x DocX-x86_64.AppImage Baixar AppImage
Windows: o instalador ainda não tem assinatura digital. Se aparecer "O Windows protegeu o computador", clique em Mais informações › Executar assim mesmo. Para sincronizar, tenha o Git for Windows instalado. Confira a integridade dos arquivos pelo SHA256SUMS.txt na página da versão.

macOS: ainda não disponível.

Apoie

Dúvidas

Perguntas frequentes

O DocX é gratuito mesmo?

Sim. Não tem plano pago, período de teste nem recurso bloqueado. O projeto se mantém com doações e com anúncios aqui no site, nunca dentro do app.

Preciso criar uma conta?

Não. Você instala e escolhe uma pasta para as notas. Para sincronizar, usa a sua própria conta do GitHub (ou de outro serviço Git).

Onde ficam as minhas notas?

Numa pasta do seu computador, como arquivos .md comuns. Se você ativar a sincronização, uma cópia vai para o repositório Git que você escolher. Nada passa por servidores do DocX, porque eles não existem.

Funciona sem internet?

Sim, tudo funciona offline. A sincronização acontece quando houver conexão.

Posso usar as notas que já tenho?

Sim. Aponte o DocX para qualquer pasta com arquivos Markdown e ele reconhece as notas, os links [[assim]], as tags e as propriedades.

O Windows diz que o instalador é desconhecido. É seguro?

O aviso aparece porque o instalador ainda não tem uma assinatura digital paga. Baixe sempre por este site e, se quiser, confira o SHA256 do arquivo na página da versão. Comprar a assinatura é um dos objetivos das doações.

E o macOS?

Ainda não há versão para Mac. Está nos planos.

Tem inteligência artificial?

É opcional. Se você já usa o Claude Code no seu computador, o DocX pode abrir um painel de conversa que lê as suas notas e propõe mudanças, que só são aplicadas quando você confirma.
