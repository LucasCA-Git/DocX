Privacidade

Política de privacidade

Versão de 10 de novembro de 2026.

Resumo

  • O aplicativo DocX não coleta nenhum dado. Não há cadastro, telemetria nem servidor do DocX.
  • Este site não tem cadastro nem formulários. Ele pode exibir anúncios do Google AdSense, e os anúncios personalizados só aparecem se você permitir.

O aplicativo

As suas notas ficam numa pasta do seu computador. Se você ativar a sincronização, elas são enviadas para o repositório Git que você escolher (GitHub, GitLab etc.), usando o Git e as credenciais do seu próprio computador. O DocX não recebe nem guarda cópia das notas, das senhas ou dos tokens.

O assistente de IA é opcional e só funciona se você já tiver o Claude Code instalado. Nesse caso, o conteúdo que você pedir para ele ler é enviado à Anthropic pela sua conta, segundo os termos dela.

Este site

Downloads e versão: os instaladores são baixados do GitHub. Para mostrar o número da última versão, o seu navegador consulta a API pública do GitHub, que recebe o seu endereço IP como em qualquer acesso a um site.

Hospedagem: o site é hospedado pelo GitHub Pages, que pode registrar o endereço IP dos visitantes por motivos de segurança.

Anúncios: quando ativos, os anúncios são servidos pelo Google AdSense. Na primeira visita perguntamos se você permite anúncios personalizados. Se permitir, o Google e seus parceiros podem usar cookies para mostrar anúncios com base nas suas visitas a este e a outros sites. Se não permitir, mostramos apenas anúncios não personalizados, que ainda podem usar cookies para limitar a frequência e combater fraudes. Você pode mudar a escolha a qualquer momento em ou nas configurações de anúncios do Google. Saiba mais em como o Google usa cookies em publicidade.

Anúncios limpos: conteúdo adulto não é permitido na rede do AdSense, e além disso bloqueamos categorias sensíveis como apostas, namoro e promessas de emagrecimento ou de dinheiro fácil. Se você vir um anúncio inadequado, avise-nos.

Doações: são processadas pelo seu banco (Pix), pelo GitHub ou pelo Ko-fi, cada um com a sua própria política. Este site não recebe dados de pagamento.

Armazenamento no navegador: guardamos só a sua escolha sobre anúncios (localStorage) e, por 30 minutos, a versão mais recente do app (sessionStorage). Não usamos ferramentas de análise de visitas.

Seus direitos (LGPD)

Você pode pedir informações, correção ou exclusão de dados pessoais. Como o site não mantém cadastro, quase sempre não há nada guardado sobre você do nosso lado. Para dados tratados pelo Google, use as ferramentas do próprio Google.
